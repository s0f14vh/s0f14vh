## 🚀 Sobre mí

Soy desarrolladora Full Stack apasionada por construir aplicaciones **robustas, seguras y con una experiencia de usuario impecable**. Actualmente cursando el Técnico Superior en Desarrollo de Aplicaciones Multiplataforma (DAM) en IES San Vicente.

### 💼 Experiencia profesional

He completado prácticas como **Desarrolladora de Software en NTT DATA** (Abril - Junio 2026), donde trabajé en el desarrollo de aplicaciones web Full Stack integrando servicios backend en Java y Spring con interfaces reactivas en Angular y Node.js. Allí aprendí la importancia del código limpio, las metodologías ágiles y el trabajo en equipo en entornos empresariales reales.

### 🎯 Mi enfoque

- **🛡️ Seguridad primero**: Especializada en ciberseguridad y cifrado de extremo a extremo (E2EE). Implementé Web Crypto API (AES-256-GCM) en mi proyecto Chatty Secure Messenger.
- **🏗️ Arquitectura sólida**: Programación Orientada a Objetos (POO), APIs REST, bases de datos relacionales y patrones de diseño.
- **⚡ Full Stack real**: Desde el backend con Java/Spring/Node.js hasta el frontend con Angular y JavaScript moderno.
- **🎮 Desarrollo de videojuegos**: Apasionada por el desarrollo de videojuegos (no solo jugarlos). Creé un FPS 3D en Godot Engine aplicando POO y sistemas de señales, lo que me ha enseñado a resolver problemas complejos de rendimiento y arquitectura en tiempo real.
- **✨ Código que importa**: Limpio, mantenible y bien documentado. Porque el código se lee más veces de las que se escribe.

##  Proyectos destacados

### 🔐 Chatty Secure Messenger
**Aplicación Web E2EE** | Node.js, Express, Socket.io, Vanilla JS, Supabase

- Plataforma de mensajería en tiempo real con arquitectura **Trust No One (TNO)**
- Cifrado de Extremo a Extremo (E2EE) con Web Crypto API (AES-256-GCM) y derivación de claves (PBKDF2)
- Gestión de sesiones sin estado (JWT) y protección de infraestructura con Helmet.js

- Desarrollo completo de un First Person Shooter aplicando arquitectura y Programación Orientada a Objetos (POO) pura en C#
- Diseño de HUD dinámico y reactivo utilizando el sistema de comunicación por Señales (Signals)
