## 🚀 Sobre mí

Soy desarrolladora Full Stack con una sólida base en **Java, Angular y Node.js**, y una pasión especial por la **ciberseguridad** y el **cifrado de extremo a extremo (E2EE)**. 

Recientemente completé mis prácticas como **Desarrolladora de Software en NTT DATA**, donde trabajé en entornos ágiles integrando servicios backend con interfaces reactivas. Esa experiencia me enseñó que el código no solo debe funcionar, sino ser limpio, escalable y seguro.

🎮 **Un plus diferente:** Me apasiona el desarrollo de videojuegos (Godot Engine + C#). Lo considero mi "gimnasio técnico": me obliga a dominar la Programación Orientada a Objetos, optimizar el rendimiento y resolver problemas lógicos complejos de forma creativa.

Mi objetivo actual es unirme a un equipo de desarrollo **FCT o Junior** donde pueda aportar mi versatilidad, seguir aprendiendo y construir software que marque la diferencia.
